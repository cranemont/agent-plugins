```markdown
## 설계 결정 (ADR)

- 아키텍처에 닿는 작업(구조·의존성·인터페이스 변경) 전에 `docs/adr/README.md` 목록을 보고, 건드리는 영역의 현행 ADR 본문까지 읽는다.
- 이미 결정된 것을 재논의하지 않는다. 작업이 현행 ADR과 충돌하면 멈추고 알린다 — 번복은 실행 전에 대체 ADR부터 쓴다.
- 되돌리기 비싼 결정을 하면 같은 변경 안에서 ADR을 남긴다. 규약과 목록: `docs/adr/README.md`
```
